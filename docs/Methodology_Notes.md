# Methodology Notes

## Valuation framework
Five-year unlevered Free Cash Flow to the Firm (FCFF) DCF.

- Historical period: FY21–FY26
- Explicit forecast: FY27E–FY31E
- Terminal value: Gordon Growth Method
- Equity value = enterprise value − debt + cash
- Per-share value uses diluted shares outstanding

## Operating forecast
The base case explicitly forecasts revenue growth, EBITDA margin, D&A/revenue, CapEx/revenue and NWC/revenue.

## Normalization
FY26 includes a reported exceptional consolidated expense of ₹414 cr. No adjustment is made to the base case, as the forecast starts from reported FY26 operating economics and does not assume this item is recurring.

Financing costs are excluded from FCFF and reflected through WACC to avoid double counting.

## WACC
The primary WACC uses a peer-derived bottom-up beta. Peer levered betas are unlevered using a Hamada-style adjustment, the median unlevered beta is calculated, and that beta is relevered to Motherson's market-value debt/equity ratio.

Observed beta is retained as a cross-check rather than the primary beta.

## Cross-checks
The workbook includes comparable-company multiples, market-implied EV/FY26 EBITDA, an exit-multiple cross-check, WACC/terminal-growth sensitivity, bear/base/bull scenarios and model integrity checks.

## Limitation
The balance-sheet analysis is a selected operating working-capital view rather than a full three-statement balance-sheet forecast.
